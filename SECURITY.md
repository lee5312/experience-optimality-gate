# Security

EOG instructions, hooks, records, catalogs, and receipts are not security boundaries and never grant authority. Native host permissions, application authorization, repository protection, and owner-side transactions remain authoritative.

Do not place credentials or secrets in EOG records, examples, issues, or test fixtures. Treat external catalog content and supplied records as untrusted data.

Report security issues privately to the repository owner rather than opening a public issue when disclosure could create material risk.
