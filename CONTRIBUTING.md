# Contributing

Keep EOG smaller than the engineering burden it removes. Before adding machinery, identify the consumer experience, inspect existing solutions, state the residual gap, and prefer the smallest compatible change.

Contributions should preserve these boundaries: no bundled model or agent runtime, no new task/receipt database, no permission-grant semantics, no claim that structural checks prove truth, and no host-support claim without corresponding evidence.

Run the deterministic Python and Node tests before proposing a change. Changes to `AGENTS.md`, schemas, lifecycle integration, or conformance semantics should include focused positive and negative tests.
